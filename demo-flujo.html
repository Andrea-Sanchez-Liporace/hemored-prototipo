Usuarios de prueba
Flujo, paso a paso
1
Un donante nuevo se registra, reserva y completa sus formulariosDonante
  • Crear cuenta → Soy donante → completar datos
  • Buscar campañas → elegir "Banco de sangre general — Ramos Mejía" (confirmación automática, el turno nace confirmado — se salta el paso del hospital) → Reservar turno → elegir horario → confirmar
  • Mis turnos → Completar formularios → F1 (tildar + firmar) → F2 (cuestionario + firmar) → confirmar
2
El médico clínico hace la entrevistaProfesional · médico
  • Turnos (pestaña Presentes) → Iniciar entrevista
  • F1: resumen de autoexclusión + historial del donante
  • F2: revisar las 34 respuestas reales — mostrar Modificar para corregir una
  • F3: cargar signos vitales → Apto/No apto → firmar → Confirmar evaluación
Para mostrar de más: pestaña Futuros → turno sin F1/F2 todavía → igual entra con Ver turno
3
Extraccionista registra la donaciónProfesional · extraccionista
  • El turno marcado apto dice Lista para donar → Registrar donación
  • Se realizó → cargar número de bolsa + ml (+ Agregar otra bolsa para sumar una segunda) → Confirmar donación → se genera el QR de F4
Para mostrar de más: No se realizó en otro turno → queda como Donación incompleta, sin F4
4
El donante cierra el círculoDonante
  • Notificaciones → completar el formulario post-donación anónimo (F4) desde el link, sin escanear el QR
